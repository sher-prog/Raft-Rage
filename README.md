# Raft Rage

Original multiplayer raft racer being built in ChatGPT Work for Shernice. **Checkpoint 0.1.0 is the deploy-first lobby skeleton, not a complete Phase 1 race.**

## Run

Node **24.22.1**. No services, secrets or database required.

```sh
npm ci
npm run build
npm start
```

Server binds `0.0.0.0` and `PORT` (default 3000), serves the browser bundle and `/ws` from the same origin. `/healthz` is a constant tiny GET. Public HTTPS chooses WSS automatically. For local dev, `npm run dev -- --port 4173` builds and serves the same app. `npm run check` runs typechecking, build and automated real-WebSocket tests. `npm run bench:skeleton` records a local lobby baseline; it does not measure race capacity.

## Current checkpoint

- Responsive Home, Create, Join and Lobby; original inline procedural/vector poster; installed system rounded font, no downloaded font asset.
- Random 4-letter codes, case/space-insensitive join and `?room=` prefill. Unique validated names. Share/copy link.
- Seats, Ready and server-enforced host mode controls. Solo creates an auto-Ready 1v1 lobby. Empty seats labeled Chill bots; no racing AI runs yet.
- Per-tab sessionStorage reconnect credential. localStorage only name prefill. No active-seat/name takeover.
- Initial/reconnect boot exchange with exact restart message. Exponential reconnect backoff, heartbeat, room retention until 20-minute no-connected-human idle expiry.
- Host migration on explicit Leave or 3-second detected-disconnect grace expiry, ordinary ex-host reclaim.
- Same-origin WS upgrade validation, payload/buffer/rate limits. No name, token, input or metadata logging by application. No analytics, login, payment, tracker or persistent player storage.
