# Raft Rage

Original multiplayer raft racer built in ChatGPT Work for Shernice. Live: https://raft-rage.onrender.com. Current build: **0.3.22**, through Phase 3H; physical mobile acceptance remains pending.

## Run

Node **24.22.1**. No services, secrets or database required.

```sh
npm ci
npm run build
npm start
```

Server binds `0.0.0.0` and `PORT` (default 3000), serves the browser bundle and `/ws` from the same origin. `/healthz` is a constant tiny GET. Public HTTPS chooses WSS automatically. For local dev, `npm run dev -- --port 4173` builds and serves the same app. `npm run check` runs typechecking, build and automated real-WebSocket tests. `npm run bench:skeleton` records a local lobby baseline; it does not measure race capacity.

## Current build

- Authoritative 60Hz races, 20Hz snapshots and 10Hz input; 1v1, 2v2, solo bots and Big Screen spectator views.
- Hippo, Frog, Bear and Capybara; heat, charge, stamina, rim walking, recoil, whack/block/stun/immunity, SYNC and Turbo.
- Swept solid banks (0.4 restitution), rocks/spikes/logs, whirlpools, catch-up pickups, crocodiles, ramp and whack-open shortcut gate.
- Original modular procedural characters and world art, toon outlines, faces, water foam/wakes, propulsion clouds, docks/spectators and gesture-unlocked synthesized music/SFX.
- Settings, first-race hints, top progress/distance/timer, results/awards, rematch, host-only debug actions and timing overlay.
- Validated names/codes, per-tab session tokens, Ready/seat authority, disconnect bot takeover, host migration, boot restart handling and room retention.
- Render Free, same-origin WebSockets, no database/accounts/analytics or downloaded assets. Character models remain replaceable by the user's separate design work.

## Verification

`npm run check` runs all cases serially with the original assertions and timing thresholds. `node scripts/benchmark-final.mjs https://raft-rage.onrender.com` measures four active rooms / sixteen real clients on Render, including characters, hazards, logs and Turbo. `node scripts/acceptance-public.mjs https://raft-rage.onrender.com` checks the public multiplayer/countdown/results/rematch flow. Historical skeleton benchmarks are retained but are not race capacity evidence.

Physical iPhone Safari/LTE, Android, audio audibility, multi-device touch/timing and mid-range phone FPS require user-operated checks. Browser emulation is not physical device evidence. Render Free may sleep or restart; no pinger or paid service was added.
